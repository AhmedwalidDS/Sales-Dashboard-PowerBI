# Item Sales Performance Dashboard | Power BI

## Project Overview
Interactive sales performance dashboard analyzing business 
operations across multiple regions and sales teams.

## Key Features
- Tracked KPIs: Total Sales, COGS, and Profit Margins
- Analyzed Chiller vs. Dry product category performance
- Monitored Sales Representatives' performance
- Visualized regional sales distribution across States/Provinces

## Tools Used
Power BI | Power Query | DAX
